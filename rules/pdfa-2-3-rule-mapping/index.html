Local-only checks¶

These checks support parsing, bounded inspection, or local model preconditions and do not map to a standalone veraPDF profile predicate.

Local rule Semantic note
PDF-PARSE-001 Operational parser gate, not an ISO conformance rule.
RESOURCE-LIMIT-001 Operational safety-limit gate, not an ISO conformance rule.
