# veraPDF 1.30.2: recursive PDF/A-1a structure tree aborts validation

## Summary

veraPDF 1.30.2 does not return a PDF/A-1a validation result for a document with a recursive logical-structure graph. The document is syntactically processable, but veraPDF aborts the validation task instead of reporting a conformance failure or a bounded parser result.

This is distinct from a RoleMap cycle. RoleMap cycles are handled normally and produce `ISO 19005-1:2005:6.8.3.4:2` as expected.

## Minimal reproducer

The repository reproducer is generated by `common::tagged_document_fixture("struct_tree_cyclic")` in `crates/page_validation/tests/common/mod.rs`. Its relevant object graph is:

```text
Catalog /StructTreeRoot 10 0 R
10 0 obj
<< /K [11 0 R] >>
endobj

11 0 obj
<< /S /P
   /P 10 0 R
   /K [11 0 R]
>>
endobj
```

The `/K` edge from the structure-tree root reaches the child, while the child points back to the root through `/P` and to itself through `/K`.

## Expected behavior

The validator should terminate and return a deterministic validation result. A bounded implementation may report an operational/resource-limit result; it must not hang or abort the validation process.

`page` reports `RESOURCE-LIMIT-001` for this input after its configured reference-depth bound is reached.

## Observed behavior

With veraPDF 1.30.2 and the PDF/A-1a profile, the differential test reports `operational`: veraPDF does not produce a normal validation result for the input. The exact exception text is preserved in the differential diagnostics produced by the test runner.

Reproducer command from the repository root:

```sh
VERAPDF_BIN=/path/to/verapdf cargo test -p page_validation --test structure_tree_atomic structure_tree_fixtures_match_pinned_verapdf_when_opted_in -- --nocapture
```

The test case is `struct_tree_cyclic` in `structure_tree_atomic.rs`.

## Impact

This prevents differential agreement for this malformed recursive structure-tree shape. It does not justify accepting the document as PDF/A-conformant. The local validator continues to reject it, and the differential manifest records the veraPDF result as an expected upstream operational failure.
